# Automation Command Center for Lead Operations

Sample portfolio project for workflow automation, webhook routing, CRM handoff, and AI-assisted lead operations work.

## What It Shows

- Dark command-center UI that differs from the existing dashboard samples
- Webhook-to-CRM workflow map with clickable automation nodes
- Lead routing queue with SLA, owner, and confidence
- Execution log for recent automation runs
- Business impact panel for time saved and missed follow-up prevention
- JSON runbook export and simulated webhook interaction

## Why This Portfolio Exists

The existing portfolio already shows dashboards, CSV cleanup, client portals, and AI message triage. This sample adds a different visual and functional genre: an automation operations center similar to the type of work clients request for Zapier, Make, n8n, webhook, CRM, and internal sales operations projects.

## Local Preview

Open `index.html` directly, or serve the folder locally:

```bash
python3 -m http.server 4190
```

Then open:

```text
http://127.0.0.1:4190
```
